# Security Policy

## Supported version

Security fixes are evaluated against the latest code on `main`. Historical portfolio releases are retained as evidence and are not maintained as production software.

## Report a vulnerability

Please use [GitHub private vulnerability reporting](https://github.com/Tianqiyuba02/enterprise-ai-knowledge-action-agent/security/advisories/new). Do not open a public issue for a suspected vulnerability and do not include real credentials, personal data, or employer information in a report.

Include the affected commit, a concise reproduction, impact, and any safe supporting evidence. This is a portfolio prototype, so response times and remediation SLAs are not guaranteed.

## Scope reminder

The public demo uses synthetic identities and business data. It does not provide production authentication, tenancy, HRIS/help-desk integration, or a bug-bounty program. Never enter secrets or real confidential information into the demo.
