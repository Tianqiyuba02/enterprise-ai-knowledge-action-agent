# Password Reset Support Procedure

## Self-service reset

Employees should first use the fictional identity portal's password-reset control. The synthetic
support team will never ask for the employee's current password, recovery code, or API key.

## Escalation

If self-service reset fails, the employee may contact the fictional IT desk and provide their
employee number and the displayed error code. Secret values must not be included in the ticket.
